# Cypress-Cinema: E2E-тестирование системы бронирования билетов

Данный проект представляет собой учебную систему бронирования билетов в кинотеатр, реализованную на стеке PHP и MySQL. В рамках проекта было проведено функциональное и интеграционное тестирование с использованием фреймворка **Cypress**.

## 🛠 Технологический стек
- **Frontend/Backend:** JavaScript, PHP, HTML/CSS.
- **База данных:** MySQL.
- **Автоматизация тестирования:** Cypress.
- **Управление данными:** Использование фикстур (fixtures) для разделения тестовых данных и селекторов.

## 🧪 Область тестирования (Scope of Testing)
Тестирование охватывает ключевые пользовательские сценарии:

1. **Административная панель:**
   - Авторизация администратора (позитивные и негативные сценарии).
   - Проверка доступа к управлению залами.
2. **Клиентская часть (Гость):**
   - Отображение расписания и списка фильмов.
   - Выбор сеанса и бронирование свободного места.
   - Проверка отображения блока с информацией о бронировании (билета) после подтверждения операции.
3. **Интеграционные тесты:**
   - Сценарий «End-to-End»: проверка доступности зала, созданного в админ-панели, на главной странице сайта.

## 🐞 Пример найденного дефекта
В ходе тестирования был обнаружен критический дефект:
- **Описание:** Прерывание работы JS-скрипта в админ-панели после успешной авторизации.
- **Ошибка:** `ReferenceError: chairChecked is not defined`.
- **Серьезность:** Блокирующая (Blocker) — невозможность управления залами после входа.
- **Статус:** Открыт.

## 🚀 Как запустить тесты
1. Клонируйте репозиторий:
   `git clone https://github.com/OlgaZotova-iong/Cypress-Cinema.git`
2. Установите зависимости:
   `npm install`
3. Запустите Cypress:
   `npx cypress open`

## 📈 Результаты
Проект демонстрирует навыки написания стабильных автотестов, работу с динамическими элементами DOM, использование селекторов и фикстур для масштабируемости тестов, а также умение проводить E2E-тестирование сложных бизнес-процессов.
